# Store X

A modern, responsive e-commerce web application built with Next.js and React. Store X features a clean UI, product carousels, category navigation, and a seamless shopping experience across all devices.

---

## Features

- 🛒 **Responsive Design:** Works perfectly on mobile, tablet, and desktop.
- 🏷️ **Product Categories:** Easy navigation through product categories.
- 🏆 **Featured & New Arrivals:** Highlighted sections for promotions and new products.
- ⏰ **Flash Sales:** Countdown timer for limited-time deals.
- 🔍 **Search Bar:** Quickly find products.
- ❤️ **Wishlist & Cart:** Add products to your wishlist or shopping cart.
- 📦 **Product Carousel:** Scroll through products with smooth navigation.
- 📱 **App Download Links:** QR code and store badges in the footer.
- 📧 **Newsletter Subscription:** Stay updated with the latest offers.

---

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/store-x.git
   cd store-x
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser:**
   ```
   http://localhost:3000
   ```

---

## Usage

- Browse categories and featured products from the home page.
- Use the search bar to find products.
- Add products to your wishlist or cart.
- Enjoy responsive layouts on any device.
